### Пожалуй расскажу немного о стеке технологий ###
1. В основе java 17
2. Пакетный менеджер maven (почему то он мне больше понравился чем grudle)
3. liquebase - для миграций базы данных
4. JPA - репозитории 
5. Dto с помощью lombok
6. Hibernate - как queryBuilder (если я правильно понимаю его предназначение)
7. Postgresql - как база данных
8. Stomp - для веб сокетов
9. bootstrap и html - фронтенд (в основном сгенерированный ии)
10. FreeMaker - понравился больше как шаблонизатор и выглядит удобнее
11. Validation - еще не так сильно плотно работал с валидацией потому что проект в разработке, и я люблю сначала сформировать его функциональную часть
12. Security - естественно для авторизации
13. docker compose - как контейнер, пока в разработке пробрасываю порт 5005 для дебага и запускаю в ручную приложение в режиме разработчика, но на будущее уже сделал примерный набросок контейнера который собирает и копирует сборку в новый образ докера где уже сборка запускается. Это хорошо для использования kubernet в будущем.

### общая сумма слагаемых ###
На самом деле не сильно отличается от symfony, или symfony от spring-boot но я вижу важные преимущества последнего, он более понятен, при этом java позволяет работать с потоками и делать паралельные вычисления.
Не претендую на экспертность, но типобезопасность и классическое ООП более привлекает простотой реализации задач. К примеру те же спецификации и предикейты более понятны чем в doctrine.
